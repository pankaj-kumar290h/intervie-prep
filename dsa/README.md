# DSA

Focused data-structures & algorithms practice, organized by topic. Every file follows the
same format: 20 curated problems, Easy → Very Very Hard, each with a problem statement,
intuition, a verified JavaScript solution, and complexity analysis.

| File | Contents |
| --- | --- |
| [array-questions.md](array-questions.md) | Arrays — hashing, two pointers, prefix sums, Kadane's, in-place tricks |
| [strings-questions.md](strings-questions.md) | Strings — sliding window, palindromes, DP on strings, KMP, Manacher's, Rabin-Karp |
| [linked-list-questions.md](linked-list-questions.md) | Linked lists — reversal, cycle detection, merging, LRU/LFU cache, skip list |
| [stacks-queues-questions.md](stacks-queues-questions.md) | Stacks & queues — monotonic stack, calculators, histogram tricks, design problems |
| [trees-questions.md](trees-questions.md) | Trees & BSTs — traversals, LCA, serialization, tries, segment trees |
| [graphs-questions.md](graphs-questions.md) | Graphs — BFS/DFS, topological sort, Union-Find, Dijkstra, MST, Tarjan's bridges |
| [dynamic-programming-questions.md](dynamic-programming-questions.md) | DP — knapsack, LIS, edit distance, interval DP, DP on grids/strings |
| [heaps-questions.md](heaps-questions.md) | Heaps & priority queues — top-k, median of a stream, scheduling, design problems |
| [backtracking-questions.md](backtracking-questions.md) | Backtracking — permutations/subsets, N-Queens, Sudoku, word search, pruning |
| [binary-search-questions.md](binary-search-questions.md) | Binary search — rotated arrays, binary search on the answer, matrix search |
| [bit-manipulation-questions.md](bit-manipulation-questions.md) | Bit manipulation — XOR tricks, bitmask DP, tries on bits, JS 32-bit gotchas |
| [data-structures.ts](data-structures.ts) | From-scratch TypeScript class implementations of every core data structure (linked lists, stack, queue, deque, heap, BST, trie, graph, union-find, LRU cache, segment tree) — for revising the internals, not the interview problems |

**Suggested study order:** Arrays → Strings → Binary Search → Linked List → Stacks & Queues
→ Trees & BST → Heaps → Backtracking → Dynamic Programming → Graphs → Bit Manipulation.
