# JS / Frontend Interview Preparation

Technical notes for a frontend / full‑stack‑leaning frontend interview. Organised by
subject area. Each file is self‑contained study material with definitions, how things
work, trade‑offs, and the follow‑up questions interviewers actually ask.

> Scope: only the technical topics from the syllabus. The experience‑sharing intros
> ("Akshay & Chirag's Experience") and the non‑technical bonus masterclasses
> (salary negotiation, resume, personal branding, LinkedIn) are intentionally omitted.

## How to use

1. Read top‑to‑bottom once for coverage.
2. For each topic, be able to answer: *What is it? How does it work under the hood?
   When would you NOT use it? What's the frontend‑specific angle?*
3. Practise the LLD exercises by actually coding them in a sandbox with a timer.
