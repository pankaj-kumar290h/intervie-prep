# Connected Speech

Native speakers don't say words one by one. Words melt into each other. If you speak
in separate clear words, you sound slow and "textbook", and – ironically – you also
understand fast speech worse. Learning connected speech fixes both.

---

## 1. Linking consonant → vowel

A final consonant jumps onto the next word's starting vowel.

- "an apple" → "a-napple"
- "turn it off" → "tur-ni-toff"
- "pick it up" → "pi-ki-tup"
- "not at all" → "no-ta-tall"
- "this is a" → "thi-si-za"

## 2. Linking vowel → vowel (insert a tiny glide)

- ...ending in "ee/i/ay/oy" + vowel → insert a `y`: "I am" → "I-yam", "he asked" →
  "he-yasked", "the end" → "thee-yend".
- ...ending in "oo/o/ow" + vowel → insert a `w`: "do it" → "do-wit", "go on" →
  "go-won", "how is" → "how-wiz".

## 3. Catenation / same consonant → hold, don't repeat

Two identical (or similar) consonants merge into one longer one:
- "black coffee" → "bla-koffee"
- "big game" → "bi-game"
- "this Saturday" → "thi-Saturday"
- "hot tea", "bad day", "half found"

## 4. Assimilation – sounds change to blend with neighbors

- `t` + `y` → "ch": "don't you" → "doncha", "what you" → "whatcha", "meet you" → "meetcha"
- `d` + `y` → "j": "did you" → "dijou / didja", "would you" → "wouldja", "could you" → "couldja"
- `s` + `y` → "sh": "miss you" → "mishou", "this year" → "thish year"
- `z` + `y` → "zh": "how's your" → "how-zhor", "as usual"
- `n` before `p/b/m` → `m`: "ten past" → "tem past", "in the bag" → "im the bag"

## 5. Elision – sounds disappear

- `t` and `d` drop between two consonants: "next day" → "nex day", "old man" → "ol
  man", "must be" → "mus be", "handbag" → "hanbag", "friendship" → "frienship".
- `h` drops in unstressed pronouns: "give her a hand" → "give er a hand", "tell him"
  → "tell im", "ask her" → "ask er". (Not at the start of a sentence.)
- Whole schwa syllables drop: "comfortable" → "comf-ter-ble", "chocolate" →
  "choc-late", "vegetable" → "vej-ta-ble", "different" → "diff-rent", "every" →
  "ev-ry", "interesting" → "in-tres-ting", "temperature" → "temp-ra-cher".

## 6. Contractions – always use them in speech

`I'm, you're, he's, we've, they'll, don't, can't, won't, isn't, wasn't, shouldn't,
would've, I'd, that's, there's, here's, let's, what's, who's`.

Saying "I am not going to do that" instead of "I'm not gonna do that" sounds stiff
and over-formal in casual speech. In a formal presentation, fewer contractions is
fine – match the register.

## 7. Common crushed phrases (learn as single chunks)

| Written | Said |
|---|---|
| going to | "gonna" |
| want to | "wanna" |
| got to / have got to | "gotta" |
| kind of / sort of | "kinda" / "sorta" |
| a lot of | "a lotta" |
| out of | "outta" |
| let me | "lemme" |
| give me | "gimme" |
| don't know | "dunno" |
| what are you | "whaddaya" |
| I don't know | "I dunno" / "'dunno" |
| because | "'cause" / "cuz" |
| probably | "prob'ly" |

Understand all of these; use the mild ones (gonna, wanna, kinda, 'cause) in casual
speech; keep the heavy ones (whaddaya, dunno) for very informal situations.

---

## How to practice

1. Take **one sentence** from your shadowing audio.
2. Write it out. Mark every link, drop, and change (use the notation above).
3. Say it slowly *with* the connections. Then speed up to the original tempo.
4. Shadow that line 10×.

Do this with 2–3 sentences a day for two weeks (Weeks 3 and 9 in the plan). It
transfers to everything else.

> ⚠️ Don't force connected speech before you're comfortable – it should *emerge*
> from speaking faster and shadowing, not be bolted on. But knowing the rules helps
> you *hear* it, which is half the battle.
